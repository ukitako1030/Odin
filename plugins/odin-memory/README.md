# Odin Memory 配布用テンプレート

会話の知識・タスク・アイデアを、自分のOdinへ保存するプラグインのひな形です。保存ルールと表示情報を収録しています。作者のURL・接続ID・認証情報は含みません。

このフォルダーをそのまま導入しても接続設定はありません。Odinリポジトリのルートで次を実行し、自分用の接続設定を含むプラグインを生成してください。

```sh
npm ci
npm run setup:plugin
```

[接続登録・生成・インストールの手順](../../docs/PLUGIN-SETUP.md)
