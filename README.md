<h1 align="center">Odin — 個人用のナレッジ・タスク管理アプリ</h1>

<p align="center">AIと話した内容や、会話の中で決まったタスクをGoogle Driveに保存。<br />Odinで見返し、整理し、タスクを管理できます。</p>

<p align="center"><sub>公開準備中 · 掲載画面の記録はサンプルデータです</sub></p>

<p align="center"><a href="#記録の関係をグラフで表示">知識の星図を見る</a> · <a href="#ローカルで試す">ローカルで試す</a> · <a href="docs/SETUP.md">セットアップガイド</a></p>

AIとの会話を、そのつどメモアプリに転記する手間を減らしたい。新たなサブスクを増やさず、手持ちのGoogle Driveに記録を蓄積したい。Odinは、この2つをきっかけに作ったアプリです。

## GPT Liveで「Odinに渡しといて」

普段の会話から、そのまま保存を依頼できます。作者はGPT Liveと接続して、次のように使っています。

| 会話中の依頼例 | Odinでできること |
| --- | --- |
| 「さっき話したこと、Odinに渡しといて」 | 会話の内容を記録として残し、あとから検索・編集 |
| 「それ、あとでやるからタスクに入れといて」 | やることを一覧で確認し、終わったらチェック |

**AIが内容を整理 → Odinを通じてGoogle Driveに保存 → Odinで確認・管理**

利用にはDriveとAI側の接続設定が必要です。対応する接続方法はAI製品・音声モード・アカウントによって異なります。詳しくは[AI接続ガイド](docs/AI-CONNECTIONS.md)を参照してください。

![Odinのホーム。今日の道しるべと記録への入口](docs/images/readme-home.webp)

名前は「思考」の鴉フギンと「記憶」の鴉ムニンを従える、北欧神話のオーディンから。毎日使うなら気分が上がるものを、という思いで、見た目はあえて厨二病全開にしています。

## メモとタスクをまとめて管理

読書メモ、アイデア、プロジェクト、タスク、買い物などを一か所で管理できます。AIからの保存だけでなく、画面の「記録する」から直接入力することもできます。

- **整理する** — タグ・出典・関連する記録を追加。
- **やることを確認する** — ホームに未完了のタスクや買い物をまとめて表示。
- **終わったらチェックする** — タスク全体や、本文中のチェック項目を完了に変更。

PC・スマートフォンに対応。背景のアニメーションは設定でオフにできます。

## 記録の関係をグラフで表示

「**知識の星図**」で、記録どうしのつながりを確認できます。関連づけた記録や同じプロジェクトの記録を線で結び、共通タグのつながりも表示できます。星を選ぶと、関連する記録や本文を開けます。

![関連する記録をたどれる知識の星図](docs/images/readme-graph.webp)

本文はMarkdownで編集できます。出典やタグも一緒に残せるほか、変更履歴から以前の内容に戻すこともできます。

## 過去の会話もファイルから取り込める

ChatGPT・Claude・Geminiの書き出しファイルや、Odinを動かしているPCのCodex履歴から、期間と会話を選んで取り込めます。

外部AIで分類・要約した内容は、元の発言と照らし合わせてOdin上で確認し、保存できます。詳しくは[AI接続ガイド](docs/AI-CONNECTIONS.md)を参照してください。

## ローカルで試す

**必要なもの：Node.js 24以上、npm**

まずはGoogle DriveやAIを接続せずに、サンプル記録で操作を試せます。リポジトリを取得し、そのフォルダーで次のコマンドを実行してください。

```sh
npm ci
npm run dev
```

ブラウザーで [http://127.0.0.1:3000](http://127.0.0.1:3000) を開くと使えます。「記録する」からメモを作ったり、「知識の星図」でサンプル記録を選んだりしてみてください。

掲載画像には撮影用のサンプルを使っています。初回起動時のサンプルとは内容が異なります。

初期設定では、記録をPC内の `.odin/vault` にMarkdownファイルとして保存します。記録と変更履歴はZIPで書き出せます。保存先はGit管理外のため、別途バックアップしてください。

### Google Drive・AIと接続する

会話から保存するには、Google Driveを保存先に設定し、利用するAIをOdinのREST APIまたはMCPに接続します。

- [セットアップガイド](docs/SETUP.md)：Driveの設定、ローカル記録の移行、ホスティング
- [AI接続ガイド](docs/AI-CONNECTIONS.md)：認証、AIとの接続、読み書きの確認

Driveは記録の保存先として使います。PC内の記録と自動で双方向同期する仕組みではありません。

Odinには分類・要約用のAI API呼び出しを内蔵していません。費用は利用するAIの契約、Driveの容量、ホスティングなどの構成によります。
