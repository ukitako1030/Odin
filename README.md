<h1 align="center">AIと話したことを、あとで使える自分の記録に。</h1>

<p align="center">Odin（オーディン）は、AIとの会話から生まれた知識・アイデア・やることを、<br />自分のGoogle Driveに残して、見返し、整理する個人用アプリです。</p>

<p align="center"><a href="#まずはローカルで試す">まずは試す</a> · <a href="#google-driveとaiをつなぐ">Drive・AIのセットアップ</a> · <a href="docs/AI-CONNECTIONS.md">ChatGPT・Codexの接続手順</a></p>

![Odinのホーム。今日のやることと、記録を探す入口](docs/images/readme-home.webp)

## 「あの話、どのチャットでしてたっけ？」を減らしたくて

AIとの会話で、いいアイデアが出た。調べものが片づいた。次にやることも決まった。でも、あとで使おうとすると、長いチャットをさかのぼることになる。別のメモアプリにまとめ直すのも、毎回だと面倒です。

ObsidianとAIを組み合わせる方法も考えましたが、自分には連携の仕組みが分かりにくく、管理のために新しいサブスクを増やすのも避けたい。**すでに使っているAIに整理を任せて、手持ちのGoogle Driveに保存し、見やすい画面で管理できたら。** それがOdinを作ったきっかけです。

会話はいつものAIで。残したい内容は自分の保管庫へ。Odinでは、そこから必要な記録を探したり、今日のやることを確認したりできます。

## 会話の途中で「Odinに渡しといて」

作者が普段使っているのは、GPT Liveで話しながら、その場で保存を頼む使い方です。

> 「今の話、あとで見返したいからOdinに渡しといて」
>
> 「それ、やることに入れといて」

接続したAIが会話の内容を整理し、Odinを通じてDriveに保存。あとからスマホで開けば、残した知識も、会話の中で決めたタスクも確認できます。別のアプリへコピーして、タイトルをつけ直す手間を減らせます。

| こんな場面で | 残しておけるもの |
| --- | --- |
| AIと調べものをしたあと | 要点、参考にした出典、次に調べたいこと |
| 仕事や制作の相談をしたあと | 決めた方針、判断の理由、次の作業 |
| 思いつきを話しているとき | まだ形になっていないアイデア |
| 日常の用事を整理するとき | やること、買うもの、期限 |

この使い方にはDriveとAIの接続設定が必要です。GPT Liveの例は作者の利用体験で、利用できるプラグインや音声モードはアカウント・環境によって異なります。[接続手順と確認方法](docs/AI-CONNECTIONS.md)を用意しています。

## デザインは厨二病全開です。悪しからず。

名前の由来は、北欧神話のオーディン。「思考」の鴉 **Hugin（フギン）** と「記憶」の鴉 **Munin（ムニン）** を従える姿を、思考と記憶をまとめるこのアプリに重ねました。

黒と深い青、紫の光、鴉、そして星図。毎日開く自分の道具なら、開くたびにちょっとテンションが上がるものにしたい。そんな好みを、そのまま見た目に詰め込んでいます。

## 残すだけで終わらせない

### 今日やることを、スマホで確認

ホームの「今日の道しるべ」に、未完了のタスク・買い物・リマインダーをまとめて表示。終わったものはその場でチェックできます。本文のチェックリストにも対応しているので、買い物や作業手順も一つずつ進められます。

<p align="center"><img src="docs/images/readme-mobile-home.webp" width="245" alt="スマートフォンで今日のやることを確認するホーム画面" /> <img src="docs/images/readme-mobile-tasks.webp" width="245" alt="スマートフォンでタスクを一覧し、完了をチェックする画面" /></p>

### 前に考えたことを、つながりから見つける

「**知識の星図**」は、記録どうしの関係をたどる画面です。関連づけた記録や同じプロジェクトの記録を線で結び、共通タグのつながりも表示できます。星を選ぶと、その記録や関連するノートを開けます。

![知識の星図。関連する記録を星と線で表示](docs/images/readme-graph.webp)

### メモも、判断の理由も、一緒に残す

知識・タスク・プロジェクト・買い物・アイデアなどを一か所で管理。文字やタグで検索でき、本文はMarkdownで編集できます。出典や関連する記録も残せるので、「何を決めたか」だけでなく「どうしてそう決めたか」も見返せます。

<p align="center"><img src="docs/images/readme-memory.webp" width="670" alt="本文、タグ、出典、チェックリストをまとめた記録の詳細画面" /></p>

画面の「記録する」から直接入力することもできます。変更履歴からの復元、ゴミ箱からの復元、記録と履歴のZIP書き出しにも対応しています。背景のアニメーションは設定でオフにできます。

### 過去のAI会話も整理する

ChatGPT・Claude・Geminiの書き出しファイルや、Odinを動かしているPCのCodex履歴から、期間と会話を選んで取り込めます。外部AIがまとめた保存候補を元の発言と照らし合わせ、確認してから記録にできます。各サービスの全履歴を自動同期する機能ではありません。

## まずはローカルで試す

**必要なもの：Node.js 24以上、npm。** リポジトリをダウンロードまたはクローンし、そのフォルダーで実行します。

```sh
npm ci
npm run dev
```

[http://127.0.0.1:3000](http://127.0.0.1:3000) を開けば、DriveやAIの設定なしで使い始められます。

1. 「記録する」から、自分用のメモやタスクを一つ作る。
2. タスクを完了にしたり、言葉やタグで記録を探したりする。
3. 「知識の星図」でサンプル記録を選び、つながりをたどる。

初期状態の保存先はPC内の `.odin/vault` です。記録はMarkdownファイルとして保存されます。このフォルダーはGit管理外なので、バックアップは別途取ってください。

掲載画像はすべてサンプルデータです。撮影用の記録と、初回起動時に入るサンプルの内容は異なります。

## Google DriveとAIをつなぐ

**① Driveを保管庫にする → ② 必要ならOdinをホストする → ③ AIにOdinを登録する**、の順で設定します。Odinは自分で起動・運用するアプリです。

```text
ChatGPT・CodexなどのAI
  ↓ 内容を整理して、Odinの接続ツールで保存
Odin ── Google DriveのMarkdown
  ↑ PC・スマホのブラウザーで検索・編集・タスク管理
```

### 1. Google Driveを保存先にする

1. Google Cloudでプロジェクトを作り、**Google Drive API**を有効にします。
2. OAuth同意画面を設定し、**デスクトップ アプリ**のOAuthクライアントを作ります。
3. `.env.example`を参考に `.env.local` を作り、`GOOGLE_CLIENT_ID` と `GOOGLE_CLIENT_SECRET` を設定します。
4. 次を実行し、表示されたURLで自分のGoogleアカウントを認可します。

   ```sh
   npm run setup:drive
   ```

5. 設定スクリプトが専用フォルダーと接続情報を用意します。ローカルの記録も移す場合は、編集を止めて `npm run migrate:drive` を実行。その後Odinを再起動します。

DriveとPC内の記録が自動で双方向同期されるわけではなく、**以後の保存先がDriveに切り替わります**。Google Cloudの設定画面、認可の期限、移行後の確認は[Driveセットアップガイド](docs/SETUP.md#google-driveを保存先にする)にまとめています。

### 2. スマホやChatGPTから届く場所で動かす

同じPCのCodexから使うなら、ローカル起動のまま接続できます。外出先のスマホやChatGPTから使う構成では、自分のOdinをHTTPSでアクセスできる場所に配置します。

Webログインの設定に加え、VercelではDrive保存と共有ロック用のRedis設定が必要です。[ホスティングの手順](docs/SETUP.md)で、必要な環境変数と確認方法を説明しています。

### 3. ChatGPTのプラグイン・CodexのMCPを設定する

MCPは、AIがOdinの検索・保存などの機能を呼び出すための接続方式です。**ChatGPTのGoogle Drive連携だけを有効にしても、Odinへの保存設定は完了しません。Odin自身を接続先に登録します。**

| 使うもの | 設定する内容 |
| --- | --- |
| **ChatGPT** | 開発者モードで、自分のOdinの `https://<自分のホスト>/api/mcp` をプラグインとして登録。本人認証のため外部OAuthプロバイダーも設定 |
| **CodexなどのMCPクライアント** | ローカルのstdioブリッジ、またはHTTPSのMCP接続先を登録し、OdinのAPIトークンを設定 |
| **その他のAI** | その製品のMCP・認証対応に合わせて接続。直接接続できない場合は、整理した内容を接続済みAIへ渡して保存 |

[AI接続ガイド](docs/AI-CONNECTIONS.md)に、**ChatGPTへの登録手順、OAuth設定、Codexの設定例、接続できないときの確認項目**を載せています。設定後は、まず状態確認と検索、次にテスト記録の保存・読み戻しまで確認してください。

## 費用と、今できることの範囲

- **いつものAIを使う構成です。** Odinには分類・要約のためのAI API呼び出しを内蔵していません。利用するAIの契約、Drive容量、ホスティング、認証・Redisなどの費用は選ぶ構成によって変わります。
- **自分一人の保管庫です。** チームへの共有や共同編集を目的としたアプリではありません。
- **期限を管理できます。** リマインダーの時刻指定通知・プッシュ通知は未実装です。
- **記録はMarkdownで残ります。** Driveへ置いた任意のMarkdownを自動で取り込む機能や、ZIPの一括復元UIはありません。
