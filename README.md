# Odin — 思考の聖域

Odinは、知識・タスク・プロジェクト・買い物・アイデアをひとつの場所に残す、**ひとりの所有者向け**のアプリです。記録はMarkdownを正本として保存します。北欧神話のHugin（思考）とMunin（記憶）をモチーフにした画面から、書く、探す、つながりをたどる操作ができます。

> この公開用リポジトリは準備中です。配布条件と画像素材の再配布権利を確認しているため、現時点でライセンスや再利用許諾は設定していません。[公開準備の状態](docs/RELEASE-STATUS.md)を確認してください。

## ローカルで使う

Node.js **24以上**とnpmが必要です。リポジトリを取得したら、ルートで実行します。

```sh
npm ci
npm run dev
```

ブラウザーで `http://127.0.0.1:3000` を開きます。開発サーバーはこのPCからの接続に限定され、初期状態では `.odin/vault` に保存します。外部サービスの認証情報は不要です。初回のサンプル記録が不要なら、`.env.example` を `.env.local` にコピーして `ODIN_SEED_EXAMPLES=0` に変更してください。保管庫はGit管理外なので、必要に応じてバックアップしてください。

設定と本番運用の前提は[セットアップガイド](docs/SETUP.md)にまとめています。

## できること

- ナレッジ、タスク、プロジェクト、買い物、アイデア、Inbox、リマインダーを作成・編集。期限、タグ、関連記録、完了・アーカイブ、履歴、ゴミ箱からの復元に対応。
- 複数語・引用句・完全一致タグを使った検索。知識の星図では、記録の関連、共通タグ、所属プロジェクトによるつながりを見渡し、個別の記録へ移れます。
- ChatGPT・Claude・Geminiの書き出しファイルや、このPCのCodex履歴から会話を取り込み。期間と会話を選び、外部AIが作った候補または原文の下書きを**確認してから**保存できます。対応形式と注意点はアプリ内の「会話を取り込む」を参照してください。
- 記録と履歴のZIP書き出し。Web、REST API、MCPは共通の保存処理 `src/lib/entries.ts` を使います。MCPでの外部AI連携には利用者自身の接続設定と認証が必要です。
- PC・スマートフォン向け画面。演出の切り替えとOSの「動きを減らす」設定に対応。

Odin自体は分類・要約のための有料AI APIを呼び出しません。会話から知識候補を作る場合は、普段使っているAIを別途利用します。接続方法は[AI接続ガイド](docs/AI-CONNECTIONS.md)を参照してください。

## 保存先と運用

標準の保存先はローカルです。任意で**自分の**Google CloudプロジェクトとOAuth認証情報を設定し、Google Driveを正本に切り替えられます。既存のローカルデータを移す場合は、[セットアップガイド](docs/SETUP.md)の手順に従ってください。Driveは自動の双方向同期ではありません。

インターネットへ公開して使うには、所有者パスワード、セッション秘密値、永続保存先などを**自分で**設定する必要があります。このアプリは共同編集や複数ユーザーの招待を想定していません。

## 開発時の確認

```sh
npm run typecheck
npm test
npm run build
```

ブラウザーの結合テストは `npm run test:e2e` です。専用のテスト用保管庫を使用します。
