<p align="center">ふと思いついたことも、今日やることも、いつか読み返したい学びも。<br />Odinは、散らばる記憶をひとつの場所で育てる、ひとりのための知識・行動アプリです。</p>

![Odinのホーム。今日の道しるべと記録への入口](docs/images/readme-home.webp)

月夜の城塞、思考の鴉 **Hugin**、記憶の鴉 **Munin**。光と霧がゆっくり動く、自分だけの記録の場所。読書メモを育てたい日も、週末の旅を考える日も、ここから始められます。演出は設定からオフにでき、端末の「動きを減らす」設定にも対応しています。

## 書き留めたことが、次の一歩になる

思考を残したいときは「記録する」から。ナレッジ、アイデア、Inbox、プロジェクトに加え、タスク、リマインダー、買い物も同じ場所で扱えます。タグや出典、関連する記録を添えておけば、後から探す手がかりになります。

ホームの「**今日の道しるべ**」には、未完了のやること・買うものを集約。期限の近いものから確かめ、詳細を開いたり、その場で完了したりできます。長いタスクの本文に書いた項目も、ひとつずつチェックできます。

## 記憶のつながりを、星図でたどる

**知識の星図**では、記録が星になり、関連づけた記録や同じプロジェクトが線でつながります。共通タグの線も表示できます。気になる星を選ぶと周りの記録が見え、そこから本文へ移れます。名前を思い出せない知識も、つながりから探してみてください。

![関連する記録をたどれる知識の星図](docs/images/readme-graph.webp)

見つけた記録には本文と出典、タグ、関連する記録を残せます。検索で戻ることも、履歴を見て以前の版に戻すこともできます。

## AIとの会話も、自分の知識に

ChatGPT・Claude・Geminiの書き出しファイルや、このPCのCodex履歴から、期間と会話を選んで取り込めます。普段使う**外部AI**で知識候補を作る場合は、元の発言という根拠と候補の内容をOdinで確認してから保存します。原文をもとに下書きする使い方もできます。Odin自体に分類・要約用のAI APIは内蔵していません。詳しくは[AI接続ガイド](docs/AI-CONNECTIONS.md)をご覧ください。

## まずはローカルで、3ステップ

Node.js **24以上**とnpmを用意してください。外部サービスの認証情報なしで試せます。

リポジトリを取得したら、フォルダー内で次の2コマンドを実行します。

```sh
npm ci
npm run dev
```

1. **開く** — ブラウザーで `http://127.0.0.1:3000` へ。最初はサンプル記録で操作を試せます。
2. **残す** — 「記録する」から、最近の気づきをひとつ。タグや関連する記録を添えてみてください。
3. **たどる** — 「知識の星図」で記録を選び、本文へ。やってみたいことはタスクに残して、今日の一歩へ。

掲載画面の「週末の旅」など36件の記録は撮影専用です。初回起動時のサンプルとは異なります。

標準では記録の**Markdownファイルが正本**となり、`.odin/vault` に保存されます。記録と変更履歴はZIPで書き出せます。保管庫はGit管理外なので、使い続ける場合はバックアップしてください。サンプル記録が不要なら、初回起動前に `.env.example` を `.env.local` にコピーして `ODIN_SEED_EXAMPLES=0` にします。

必要になったら、自分のGoogle CloudプロジェクトとOAuth認証情報を設定して、保存先をGoogle Driveへ切り替えられます。Driveは自動の双方向同期ではありません。MCPを使った外部AIとの接続にも別途設定と実際の接続確認が必要です。手順は[セットアップガイド](docs/SETUP.md)にまとめています。
