# 素材の公開前確認

このリポジトリは非公開の配布準備版です。コード・画像のライセンスはまだ設定していません。画像を含む現状の一式を公開してよいという判断は行っていません。

## 確認が必要な素材

人物イラストの元資料には第三者サイト掲載画像が使用されており、元画像の切り抜き・合成・画像編集を経た素材が含まれます。生成AIで編集されたことだけでは再配布の可否は確定しません。

- `odin-refined-cutout.webp`: 元の人物切り抜きを修復した編集素材。
- `odin-reference-realm.webp`: 元の人物を合成した背景。過去のCSS宣言にも参照が残る。
- `odin-realm-unified.webp`、`hugin-odin-palette.webp`、`munin-odin-palette.webp`: 同じ人物資料を参照した背景・カラス素材。公開用の独立した制作または権利確認を検討する。

その他の採用背景・カラス・雲にも過去の参照資料との関係があるため、まとめて確認対象とします。現在参照される素材だけを収録し、参照元画像そのものや制作途中の未使用画像は収録していません。

## 今後の選択

1. 再配布の許諾を確認し、必要な表記と配布条件を整える。
2. 公開版専用のオリジナル素材へ置き換え、PC/スマホで見た目を再検証する。

公開専用の差替素材を使う場合、元の個人用アプリは維持し、配布元のファイル一覧で公開用素材を割り当てます。
