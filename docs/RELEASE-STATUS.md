# 公開準備の状態

この文書は公開用リポジトリの準備状況を示します。**現時点では非公開の準備版で、公開済みの配布物ではありません。**

- 過去のGit履歴を引き継がず、ファイル一覧で選んだコード・文書・採用画像だけを収録しています。個人の保管庫、環境ファイルの実値、内部運用記録、既存スクリーンショットは除外しています。
- テキストの代表的な秘密形式・個人ホスト・個人パスを走査し、元環境の長い設定値との一致も検査しました。完全な秘密情報監査や画像内情報の自動検査を保証するものではありません。
- ライセンスと、採用する画像・生成素材の再配布権利は未確定です。[素材の公開前確認](ASSET-REVIEW.md)を参照してください。ライセンスを設定するまで、再利用を許可する表記は置きません。
- 現行表示に必要な画像を非公開で収録しています。画像の権利確認または置き換えが終わるまで公開しません。検証用スクリーンショットはGit管理から除外しています。
- 外部AI製品、Google Drive、ホスティング環境は各利用者自身の認証情報で設定し、接続を検証する必要があります。
